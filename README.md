# 🚀 AI Hub

AI Hub is a modern **AI SaaS platform** that brings multiple AI tools into one powerful workspace.
It allows users to interact with AI, manage conversations, and explore intelligent features through a clean and immersive interface.

---

## ✨ Features

* 🤖 AI Chat Workspace
* 🧠 Multiple AI Tool Integration
* 🔐 Secure Authentication
* 💬 Conversation History
* 🎨 Modern Glassmorphism UI
* ⚡ Fast and Responsive Interface
* 🌙 Dark Mode Experience
* 📊 Scalable SaaS Architecture

## ⚙️ Installation

Clone the repository

```
git clone https://github.com/KaparapuBharath/ai-hub-project.git
```

Navigate to project

```
cd ai-hub-project
```

Install dependencies

```
npm install
```

Start development server

```
npm run dev
```
